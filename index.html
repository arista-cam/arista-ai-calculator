Changelog

v1.5.3 — July 2025

  • Single-tier LPO toggle — FRO/LPO toggle now appears for single-tier designs with 800G spine optics even when host NIC speed is below 800G (e.g. 400G via breakout); note clarifies LPO applies to switch-side optics only

v1.5.2 — July 2025

  • Print to PDF — Print button in the results tab bar generates a clean, report-style PDF with Arista branding, config summary, all tabs shown linearly, and a dated footer
  • Modular comparison labels — "Your Design" cards now include the tier (e.g. "Two-Tier All-Fixed" instead of "All-Fixed")
  • NIC breakout optics fix — switch-side optics now correctly show 800G transceivers with breakout when NIC breakout reduces link speed, halving optic count
  • LPO hidden for 1.6T — FRO/LPO toggle hidden when fabric includes 1.6T optics (LPO not yet available at 1.6T)
  • Topology speed labels — displays "1.6T" throughout topology views instead of "1600G"; host link labels show physical port grouping for 1.6T leaf switches

v1.5.1 — July 2025

  • 1.6T optic names — spine optics now show announced product names: OSFP 1.6T 2XDR4 (dual MPO-12, 2km) for 200G SerDes platforms, OSFP 800G XDR4-G (gearbox) when a 100G SerDes platform connects to 200G-lane fiber
  • Single-tier scale-out — target GPU count now drives chassis/platform sizing in single-tier mode with day-1 utilization shown
  • Aggregate BW fix — multi-plane summary correctly shows per-GPU bandwidth when GPUs connect to one plane (distributed)

v1.5.0 — July 2025

  • 1.6T (1600G) Ethernet support — spine and host speed dropdowns now include 1.6T; optic types, power estimates, and breakout logic all support 1.6T fabrics
  • 7060XE7 platform — Arista 7060XE7 with 64 OSFP-1.6T ports (128 effective 800G-equivalent), 4RU fixed form factor
  • Per-platform port speed — platform dropdowns auto-filter to show only platforms that support the selected spine/host speed
  • Decoupled spine speed — spine speed is independently selectable; enables 800G hosts with 1.6T spine fabric
  • Dynamic breakout labels — host port breakout labels update based on leaf platform (e.g. "1:2 (1.6T → 2× 800G)")
  • Mixed-speed optics — optics tables show correct transceiver types per side when leaf and spine have different port speeds

v1.4.2 — July 2025

  • Guided sidebar flow — Cluster Size opens by default; each section has a Next button that collapses the current section and opens the next, creating a wizard-style configuration flow
  • Config summary chips — collapsed sections show a compact summary of configured values (e.g. "512 GPUs · 64 nodes", "Two-tier · Training") so you can see your selections at a glance
  • Optics & Power tab — merged Optics and Power into a single combined tab so the LPO toggle immediately reflects in power figures
  • Scale-out planning — optional target GPU count pre-provisions the spine/super-spine layer for future growth while sizing leaves for day-1 deployment; Optics & Power tab shows Day-1 vs Planned toggle with full breakdowns for both scenarios
  • LPO toggle fix — FRO/LPO toggle now correctly shows for two-tier, three-tier, and DES designs (800G spine optics always support LPO); hidden only for single-tier at sub-800G host speed
  • Arista logo — replaced placeholder icon with Arista Networks wordmark in the top bar
  • Host port breakout tooltip — info icon on the breakout selector explains how 800G ports split into lower-speed host links

v1.4.1 — July 2025

  • Spine balance fix — Single-Plane vs Multi-Plane comparison cards now apply the same balance adjustment as the main calculation, fixing mismatched spine counts
  • B300 GPU defaults — NVIDIA B300 now correctly defaults to 2× ConnectX-7 at 400G instead of 1× ConnectX-8 at 800G

v1.4 — July 2025

  • Tabbed results pane — results organized into Summary, Fabric, and Optics & Power tabs to reduce clutter; selected tab persists across recalculations
  • NIC breakout topology fix — multi-plane rail view now correctly shows all GPUs connecting to every plane (e.g. 8×200G per plane instead of 4×200G); NIC expand animation updated to match
  • Spine optics for breakout — spine-facing optics now show OSFP 800G 2DR4 (dual MPO-12) instead of DR8 (single MPO-16) when uplink breakout is active, matching the natural connector topology for 2:1 breakout

v1.3 — July 2025

  • Modular Spine Advantage — side-by-side comparison of modular 7800R4 chassis vs all-fixed designs showing platforms, rack space (RU), optics, and power with per-row highlighting and recommendation notes
  • GPU / NIC selection — choose from NVIDIA (GB300, GB200, B300, B200, H200, H100) and AMD (MI350X, MI325X, MI300X) with auto-configured NIC and link speed
  • Training / Inference toggle — workload-aware guidance for fabric design (E-W vs N-S traffic patterns)
  • FRO / LPO optics — renamed from Conventional, added annual OpEx savings estimate and CapEx guidance for 800G modules
  • Flow visualization — click two compute nodes to trace traffic path with animated packets and device count classification (intra-rail, inter-rail, intra-pod, inter-pod)
  • Topology export — PNG and SVG via Export dropdown in the topology viewer
  • Topology redesign — Fat Tree / Rail pill toggle replaces dropdown; multi-plane always shows all planes with correct rail-optimized GPU-to-plane mapping (GPUs 0–3 → Plane 1, 4–7 → Plane 2)
  • GPU/NIC expand — double-click a host to see per-GPU leaf connections inline (no overlay); lines draw to real leaf positions
  • Spine-link breakout — host breakout auto-applies to spine links, fixing 8192-GPU 2×400G multi-plane topologies
  • 3-tier naming — renamed to Super-spine / Spine / Leaf with connectivity metrics (full/partial mesh)
  • 400G LPO removed — LPO only shown for 800G optics (the only speed where it exists)
  • Multi-plane naming — renamed from "MRC Multi-Plane" to "Multi-Plane"
  • NIC breakout toggle — Distribute / NIC Breakout pill for multi-plane with fewer NICs than planes
  • Leaf platform fix — 7800R4 chassis no longer suggested as leaf switches
  • Changelog — version history accessible from the top bar
