Changelog

v1.9.1 — September 2025

  • Advanced mode warning — modal dialog with acknowledgement checkbox before entering Advanced mode, warning that overriding values can produce invalid designs
  • GPU/NIC first — GPU/NIC selection moved to the first sidebar section above Cluster Size for a more natural configuration flow
  • Leaf fill order — new toggle in Cluster Size: Average (even distribution with rail alignment) vs Left to Right (pack each leaf to capacity sequentially, skip rail alignment)
  • Spine sizing toggle — new Full Mesh vs Minimal toggle in advanced Switch Configuration; Minimal uses fewest spines with bundled uplinks
  • Simple mode spine fix — simple mode now auto-selects minimum viable spine count instead of defaulting to full-mesh topology
  • Spine utilization callout — results show spine port utilization percentage and display an info note when the spine layer is overprovisioned with exact savings
  • NVL72 switch defaults — GB300 NVL72 and GB200 NVL72 now default to 7060XE7 (1.6T), matching Vera Rubin NVL72

v1.9.0 — August 2025

  • Slide export redesign — Arista-branded slide output with blue title bar, rounded boxes, thicker connection lines, Arista logo in footer, and Helvetica Neue font throughout for a professional deck-ready look
  • Larger slide text — all labels, BOM headings, switch names, port badges, and node names scaled up for readability when projected
  • Fabric tier in simple mode — tier selector (Single / Two-tier / Three-tier / DES) now visible in Simple mode so users can override the GPU default without switching to Advanced
  • Action panel — replaced inline Logical Data Path diagram with a dedicated action sidebar (Download Slide, Copy Slide, Print to PDF, Topology) using solid Arista-blue buttons
  • B300 NIC default fix — B300 now defaults to CX8 SuperNIC (800G) with single-NIC breakout across 2 planes (2×400G), matching reference architectures; previously defaulted to CX7 which produced incorrect leaf counts
  • Per-GPU default platforms — B300 defaults to 7060X6 (800G serdes) and Vera Rubin NVL72 defaults to 7060XE7 (1.6T serdes) to match GPU NIC speeds
  • Rack-alignment fix — large rack-scale clusters (e.g. VR NVL72 at 96 racks) no longer fail with uplink bundle errors; rack boundary alignment is skipped when it would exceed spine capacity
  • Smallest spine default — simple mode now selects the smallest spine platform that fits the current demand, only upsizing when scale-out planning is enabled

v1.8.0 — August 2025

  • NVIDIA Rubin GPU support — added Vera Rubin NVL72 (72 GPUs, 2× CX9 800G per GPU), DGX Rubin NVL8, and HGX Rubin NVL8 (8 GPUs, 1× CX9 800G per GPU) to the GPU model selector
  • ConnectX-9 NIC — added NVIDIA ConnectX-9 (800G) to the NIC selector, auto-selected for all Rubin GPU models

v1.7.0 — July 2025

  • Storage network module — optional storage fabric design with two connection modes: Shared Frontend (storage nodes connect to existing FE leaves) or Dedicated Fabric (independent storage leaf-spine with its own platform selection and oversubscription)
  • Storage node sizing — GPU ratio dropdown (1:8, 1:16, 1:32, 1:64) automatically calculates storage node count from cluster size
  • Storage optics & power — separate optics and power estimates for storage switches (SFP28 25G, QSFP28 100G), with amber-colored sections in the combined Optics & Power tab
  • Storage topology integration — D3 topology viewer shows storage nodes and dedicated switches with amber edges; shared mode connects storage to frontend leaves
  • Storage inline diagram — Storage Logical Data Path diagram appended below frontend diagram in results

v1.6.0 — July 2025

  • Frontend network module — optional frontend fabric design alongside the backend AI training network, with its own leaf/spine topology, oversubscription control, and platform selection (7050SX3, 7050CX3, 7280CR3)
  • Frontend optics & power — separate optics breakdown and power estimates for frontend switches (SFP+ 10G, SFP28 25G, QSFP28 100G), merged into a combined Optics & Power tab with Backend/Frontend sections
  • Frontend topology integration — D3 topology viewer shows frontend leaf/spine tiers below hosts with green edges, backend/frontend divider, and NIC expansion renders dashed FE links downward
  • Combined summary metrics — when frontend is enabled, Summary tab shows combined BE + FE totals for switches and optics, with colored section headers
  • Frontend inline diagram — Front-End Logical Data Path diagram appended below the backend diagram in results
  • Alternative platform options — platform suggestions replaced with comparison cards in the Summary tab after calculation, showing up to 3 alternatives with % diff badges for switches, optics, RU, and power, plus an "Apply & Recalculate" button
  • Uplinks per spine — "Balance topology" toggle replaced with an "Uplinks per spine" dropdown that shows valid divisor options with resulting spine counts (e.g. "2 (8 spines/plane)"); topology is now always balanced
  • NICs per GPU moved — "Links per GPU" renamed to "Physical NICs per GPU" with info tooltip, moved from Cluster Size to the Optics section where it logically belongs
  • GPU NIC link speed — "Host NIC link speed" renamed to "GPU NIC link speed" with an info tooltip explaining the distinction from breakout

  • Single-tier summary chips — switch summary now shows only the chassis platform (not redundant leaf+spine), and optics summary shows host speed only since single-tier has no separate spine speed
  • Renamed — tool renamed from "AI Backend Network Calculator" to "AI Network Calculator"

Advanced Mode

Advanced mode gives you full control over all fabric parameters including line card ports, planes, rails, oversubscription ratios, and optics selection.

Overriding these values can produce invalid or unbuildable designs. Only use advanced mode if you are familiar with Arista AI fabric architectures and understand the impact of each setting.
